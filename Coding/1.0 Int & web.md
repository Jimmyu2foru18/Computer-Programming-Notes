# Internet & Web Technologies I

## Foundations: HTML5, CSS3 & JavaScript

The frontend stack powers user experiences on the web. Master the foundational technologies before advancing to frameworks.

### Key Topics
- HTML5 semantics, document outline, and SEO
- CSS box model, specificity, and cascade
- Flexbox and Grid for layout
- Responsive design: media queries, clamp(), and container queries
- JavaScript: variables, types, and scope
- DOM manipulation, events, and event delegation
- Async programming: callbacks, promises, and async/await
- ES6+ features: destructuring, spread, modules, and optional chaining
- Project: building a portfolio site with semantic markup

```html
<!-- Example: Semantic HTML5 structure -->
<article>
  <header>
    <h1>Article Title</h1>
  </header>
  <section>
    <p>Content goes here.</p>
  </section>
</article>
```
