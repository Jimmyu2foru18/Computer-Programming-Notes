# System Design I

## Fundamentals & Frontend Architecture

System design is the process of defining architecture, components, and data flow for scalable applications.

### Key Topics
- System design principles: scalability, reliability, availability
- Requirements gathering: functional vs non-functional
- Capacity estimation: QPS, storage, and bandwidth calculations
- Frontend architecture: component design and state management
- Frontend state management: Redux, MobX, Context, and signals
- Build tools: Webpack, Vite, Turbopack, and esbuild
- Frontend optimization: code splitting, lazy loading, and caching
- Frontend testing: unit, integration, and visual regression
- Architectural patterns: monolith, microservices, serverless
- Project: designing a front-end blueprint

```text
Example Capacity Estimation:
- 1M DAU, 100 requests/user/day = 100M requests/day
- 100M / 86400s ≈ 1,200 QPS
- Peak traffic (3x average): ~3,600 QPS
```
