# C# II

## Advanced C# & .NET Internals

This section covers advanced C# features including LINQ, async/await, and reflection.

### Key Topics
- Encapsulation, properties, and backing fields
- Inheritance, virtual/override, and sealed classes
- Polymorphism, abstract classes, and interfaces
- Interfaces, explicit implementation, and generics
- Exception handling: catch filters, when, and using declarations
- File I/O: StreamReader/Writer, File APIs, and async file operations
- Delegates, events, and the event pattern
- LINQ: query syntax, method syntax, and deferred execution
- Async/await, Task Parallel Library, and value tasks
- Generics, constraints, covariance, and contravariance
- Reflection, attributes, and custom descriptors

// Example: LINQ query
