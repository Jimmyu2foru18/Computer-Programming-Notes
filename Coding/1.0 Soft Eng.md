# Software Engineering I

## Fundamentals & OOP Principles

Software engineering applies engineering principles to software development for quality, maintainability, and scalability.

### Key Topics
- Software development lifecycle (SDLC) overview
- Encapsulation, information hiding, and data abstraction
- Inheritance, is-a vs has-a relationships, and composition
- Abstraction, abstract classes, and interfaces
- SOLID principles: SRP, OCP, and their application
- SOLID principles: LSP, ISP, DIP, and dependency inversion
- Clean code principles: DRY, KISS, YAGNI
- Creational design patterns: Singleton, Factory, Builder, Prototype
- Structural design patterns: Adapter, Decorator, Facade, Proxy
- Behavioral design patterns: Observer, Strategy, Command, Iterator
- Patterns in practice: combining patterns for real-world solutions

```python
# Example: Strategy Pattern
class SortStrategy:
    def sort(self, data): pass

class QuickSort(SortStrategy):
    def sort(self, data): return sorted(data)
```
