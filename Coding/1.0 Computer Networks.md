# Computer Networks I

## Networking Fundamentals & Architecture

Computer networks enable communication between devices through standardized protocols and hardware.

### Key Topics
- Network architecture: client-server, peer-to-peer, and cloud
- Network topologies: bus, star, ring, mesh, and hybrid
- LAN, WAN, MAN, and scaling considerations
- Network hardware: NICs, switches, routers, and firewalls
- OSI model: layers 1-2 (Physical, Data Link)
- OSI model: layers 3-4 (Network, Transport)
- TCP/IP stack: 5-layer model and encapsulation
- IPv4 addressing: classes, subnetting, and CIDR notation
- IPv6: address format, transition strategies, and benefits
- TCP: connection management, flow control, and reliability
- UDP: datagrams, use cases, and real-time protocols

```bash
# Example: Network diagnostics
ipconfig /all        # Windows
ifconfig             # Linux/macOS

```
