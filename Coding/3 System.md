# System Design III

## Scalability, Security & Observability

Advanced system design covering production concerns: scaling, deployment, security, and monitoring.

### Key Topics
- Scalability: vertical vs horizontal, load balancing, and sharding
- Security: authentication (OAuth, JWT), authorization (RBAC, ABAC)
- CI/CD pipelines: testing, building, and automated deployment
- Infrastructure as Code: Terraform, CloudFormation, and Pulumi
- Cloud hosting: AWS, GCP, Azure, and multi-cloud strategies
- Observability: metrics, logs, traces, and the three pillars
- Reliability: SLAs, SLOs, error budgets, and chaos engineering
- Disaster recovery: backups, replication, and RTO/RPO
- Advanced architecture project: end-to-end system design
