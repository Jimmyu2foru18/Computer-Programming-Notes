# Linux Administration I

## Installation, CLI & Filesystem

Linux powers the majority of servers and cloud infrastructure. Master the command line and system internals.

### Key Topics
- Linux history, distributions, and kernel vs user space
- Installation: partitioning, bootloaders, and dual-booting
- GUI environments: GNOME, KDE, and window managers
- CLI basics: shell prompt, commands, and man pages
- Filesystem hierarchy: FHS, /bin, /etc, /var, /home
- File operations: cp, mv, rm, touch, and wildcards
- Permissions & ownership: chmod, chown, and special bits
- Package management: apt, yum/dnf, and pacman
- Redirection & piping: stdin, stdout, stderr, and pipelines
- Text processing: grep, sed, awk, cut, and sort

```bash
# Example: Common Linux commands
ls -la /var/log
find /home -name "*.conf" -type f
grep -r "error" /var/log/syslog
```
