# Java I

## Introduction & Core Syntax

Java is a class-based, object-oriented language designed for portability and security.

### Key Topics
- JVM architecture and bytecode
- Variables, primitives, and reference types
- Operators, precedence, and type promotion
- Control flow: if/else, switch, and ternary
- Loops: for, while, do-while, and enhanced for
- Arrays, multidimensional arrays, and initialization
- String handling, immutability, and StringBuilder
- Methods: overloading, varargs, and recursion
- Classes, objects, and reference semantics
- Constructors, overloading, and the this keyword
- Static members, final, and constants

```java
// Example: Basic Java structure
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```
