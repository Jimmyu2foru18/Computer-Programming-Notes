# C# I

## Introduction & .NET Ecosystem

C# is a modern, type-safe, object-oriented language targeting the .NET platform.

### Key Topics
- .NET runtime, CLR, and managed execution
- Variables, primitives, and nullable value types
- Operators, precedence, and pattern matching
- Control flow: if/else, switch expressions, and guards
- Loops: for, foreach, while, and do-while
- Arrays, jagged arrays, and initialization
- Strings, interpolation, and verbatim literals
- Methods: parameters, overloading, and local functions
- Classes, objects, and reference types
- Constructors, init-only setters, and primary constructors
- Properties, auto-properties, and expression-bodied members
