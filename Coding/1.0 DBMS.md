# Database Management Systems I

## Fundamentals & Relational Model

DBMS provides structured data storage, retrieval, and management with integrity guarantees.

### Key Topics
- Database architecture: 3-schema model and data independence
- Relational model, relations, tuples, and domains
- Relational algebra: selection, projection, join, and set operations
- SQL basics: DDL (CREATE, ALTER, DROP) and keys
- SQL basics: DML (INSERT, UPDATE, DELETE) and joins
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX, and GROUP BY
- Subqueries, CTEs, and correlated subqueries
- Entity-Relationship modeling: entities, attributes, relationships
- Normalization: 1NF, 2NF, 3NF and functional dependencies
- Normalization: BCNF, 4NF, 5NF and multi-valued dependencies
- Integrity constraints, views, and security

```sql
-- Example: SQL join and aggregation
SELECT department, COUNT(*) as employees
FROM employees
GROUP BY department
HAVING COUNT(*) > 5;
```
