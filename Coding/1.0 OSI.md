# OSI Model

## Comprehensive Technical Reference

The OSI model is the foundational framework for understanding network communication across seven layers.

### Key Topics
- OSI model history and ISO standardization
- Layer 1: Physical layer, signaling, and transmission media
- Layer 2: Data Link layer, framing, MAC, and error detection
- Layer 3: Network layer, IP, routing, and fragmentation
- Layer 4: Transport layer, TCP/UDP, ports, and multiplexing
- Layer 5: Session layer, dialog control, and synchronization
- Layer 6: Presentation layer, encryption, and data representation
- Layer 7: Application layer, protocols, and user services
- PDU (Protocol Data Unit) at each layer
- Troubleshooting by layer and common failure modes

```text
Application  | Data
Presentation | Data
Session      | Data
Transport    | Segment
Network      | Packet
Data Link    | Frame
Physical     | Bit
```
