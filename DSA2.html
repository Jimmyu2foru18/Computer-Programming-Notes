Data Structures & Algorithms: Advanced Structures & Optimization

1. Binary Search Trees (BST)

A Binary Search Tree maintains the invariant that all left descendants are less than the node, and all right descendants are greater. This enables O(log n) search, insertion, and deletion in the average case.

Degenerate Trees

If data is inserted in sorted order, a BST degenerates into a linked list, yielding O(n) operations. Self-balancing trees (AVL, Red-Black) solve this by performing rotations during insertion and deletion to maintain height balance.

2. Balanced Trees: AVL & Red-Black

AVL Trees maintain a balance factor of -1, 0, or +1 at every node. They provide stricter balance than Red-Black trees, yielding faster lookups but slower insertions due to more frequent rotations.

Red-Black Trees are used in the C++ STL (std::map, std::set) and the Linux kernel. They guarantee O(log n) operations with fewer rotations than AVL, making them better for write-heavy workloads.

3. Heaps & Priority Queues

A heap is a complete binary tree satisfying the heap property: each node is greater than (max-heap) or less than (min-heap) its children. Heaps enable O(1) access to the minimum/maximum element and O(log n) insertion and extraction.


import heapq

heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)

print(heapq.heappop(heap))  # 1 (min element)

4. Graphs: Representations & Traversals

Graphs model networks. The two primary representations are:

  • Adjacency Matrix: O(V²) space, O(1) edge lookup. Efficient for dense graphs.
  • Adjacency List: O(V + E) space, O(degree) edge lookup. Efficient for sparse graphs.

BFS explores level-by-level using a queue, finding shortest paths in unweighted graphs. DFS explores as deep as possible using a stack (or recursion), useful for cycle detection and topological sorting.

5. Dynamic Programming (DP)

DP solves complex problems by breaking them into overlapping subproblems, storing results to avoid redundant computation. The key insight is identifying optimal substructure and overlapping subproblems.

Memoization vs. Tabulation

Memoization (top-down) uses recursion with a cache. Tabulation (bottom-up) uses iteration and a table. Tabulation is often more space-efficient and avoids recursion overhead.


def fib(n, memo={}):
    if n in memo: return memo[n]
    if n <= 1: return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]

6. Optimization: Greedy & Branch & Bound

Greedy algorithms make locally optimal choices at each step, hoping to find a global optimum. They work for problems with the "greedy choice property" (e.g., Huffman coding, Dijkstra's algorithm).

Branch and Bound systematically enumerates candidate solutions, pruning branches that cannot yield better solutions than the best found so far. It is used for NP-hard problems like integer programming.
